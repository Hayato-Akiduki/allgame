# PRO TRADER SIMULATOR (マーケット・マスター)
### リアルタイム株式デイトレード・シミュレーションゲーム

プロのデイトレーダーや機関投資家が使用する本格的な取引画面（MarketSpeed / TradingView / Bloomberg風）を再現した、ブラウザで遊べるリアルタイム株取引ゲームです。

---

## 🎮 特徴と見どころ

1. **秒単位で動くリアルタイム・マーケット**
   - 幾何ブラウン運動（ランダムウォーク）と板の需給をシミュレート。
   - 15秒ごとにローソク足（陽線＝赤、陰線＝青）が形成され、テクニカル分析（短期SMA5、長期SMA20、出来高）が可能です。
   - ゲーム速度は **一時停止(⏸) / 等速(1x) / 2倍速(2x) / 5倍速(5x)** を自由に切り替え可能。

2. **リアルな板情報（気配値）と歩み値（Time & Sales）**
   - 上下8本の気配値（買い板・売り板）が数量バー付きでリアルタイムに変動。
   - **板の気配値をクリックするだけで、発注パネルにその価格が自動入力**されます。
   - プレイヤーの指値注文がある価格には「自」タグが表示されます。

3. **信用取引（レバレッジ3倍）＆ 空売り**
   - 現物取引に加え、資金効率の高い**信用取引（3倍レバレッジ）**を搭載。
   - 下落トレンドの銘柄には**「信用新規売り（空売り）」**を仕掛け、値下がりしたところで買い戻して利益を狙えます。

4. **速報ニュース・市場イベントシステム**
   - 突然入る**「決算発表」「新薬治験成否」「SNSのイナゴ煽り」「日銀金利政策発表」**などの速報ニュース。
   - ニュース発生時にはアラートチャイムとともに株価と板が急騰・暴落します。

5. **個性豊かな全12銘柄**
   - `7203` **トヨモータース**（輸送用機器 / 安定大型・手堅い）
   - `6758` **ソニックエレック**（電気機器 / ハイテク主力・指数連動型）
   - `9984` **ソフトベンチャーズ**（情報・通信 / AI投資・高ボラティリティ）
   - `4592` **ネオバイオファーマ**（医薬品 / 新薬ベンチャー・超絶乱高下）
   - `3990` **ロケットミーム宇宙**（サービス・宇宙 / SNS仕手株・梯子外し注意）
   - `8306` **メガバンク連合**（銀行業 / 金利敏感・マクロイベント株）
   - `6920` **レーザーフォトニクス**（電気機器 / 超値がさ半導体主力・デイトレ主戦場）
   - `7974` **ニンテンドリーム**（その他製品 / 世界ブランド・エンタメIP王者）
   - `7011` **大和重工ディフェンス**（機械 / 国策・防衛・宇宙重工）
   - `9101` **日本オーシャン郵船**（海運業 / 超高配当・コンテナ運賃市況株）
   - `8058` **スリーダイヤ商事**（卸売業 / バフェット銘柄・総合商社・資源）
   - `3350` **メタビットプラネット**（情報・通信 / 暗号資産・ビットコイン連動の超絶ボラ低位株）

6. **ダークモード ＆ ライトモード切替対応**
   - ヘッダー右側のボタンで、洗練された**「ダークモード」**と明るく視認性の高い**「ライトモード」**をワンクリックで切り替え可能。
   - 高DPI（Retina）ディスプレイでもチャートの線や文字が極めて鮮明・シャープに描画されます。

7. **Web Audio API による本格的な効果音**
   - 発注音、約定チャリン音、損切り警告音、ニュース着信音をブラウザ標準機能で合成出力（外部音声ファイル不要）。

8. **手数料・税金**
   - 売買手数料：約定代金の0.1%（最低100円）。新規・決済それぞれにかかり、実現損益は手数料込みで計算されます。
   - 税金：特定口座（源泉徴収あり）と同じく、通算した実現益の20.315%を決済のたびに源泉徴収。損失が出ると徴収済みの税金が還付されます。
   - 「成績分析」タブで手数料と税金の累計を確認できます。

9. **ゲーム進行の自動保存**
   - 資産・建玉・注文・取引履歴・チャート・実績などをブラウザに自動保存し、次に開いたときは続きから再開します。
   - 最初からやり直すときは、ヘッダー右上の「🔄 リセット」を押してください。

10. **最高資産ランキング**
   - 「🔄 リセット」でやり直すたびに、そのゲームの最高資産・最終資産・営業日数・取引回数・称号が記録され、上位10件がランキングに残ります（ランキングはリセットしても消えません）。
   - ヘッダー左の称号バッジをクリックすると、ランキングと、プレイ中のゲームの現在の順位を確認できます。

## 🚀 遊び方

### 起動方法
ブラウザで直接 `index.html` を開くだけですぐにプレイできます。

- エクスプローラーで `c:\Claude\kabu\index.html` をダブルクリック
- またはブラウザ（Chrome / Edge 等）にドラッグ＆ドロップ

### 基本操作
1. **銘柄選択**: 左側のウォッチリストから気になる銘柄をクリックします。
2. **注文**:
   - **現物 / 信用**: 口座区分を選択します（空売りをしたい場合は「信用取引」を選択）。
   - **買い / 売り**: 方向を選択します。
   - **成行 / 指値**: 成行は即座に現在の価格で約定。指値は希望価格に達した時点で自動約定します（板をクリックすると指値に瞬時入力されます）。
   - **株数**: 100株単位で入力、または「+100」「+500」「+1000」ボタンで入力。
   - **発注**: 「発注」ボタンを押すと注文が通ります。
3. **ポジション管理**:
   - 画面中央下の「保有建玉・現物」タブで現在の含み損益を確認できます。
   - 「決済」ボタンを押すと、ワンクリックで利益確定・損切りが実行されます。
   - 右上の「全返済・売却」ボタンで全ポジションを一括成行決済することも可能です。
